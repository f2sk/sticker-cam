# sticker-cam

透過PNGステッカー／フレームを使って、写真やカメラ映像を加工するスマホ向けWebツール。
**すべての処理がブラウザ内（端末上）で完結し、外部サーバーへのデータ送信は一切ありません。**

## ツール

| ツール | URL | 概要 |
| --- | --- | --- |
| **Camera** | [f2sk.github.io/sticker-cam/](https://f2sk.github.io/sticker-cam/) | カメラ映像や既存写真にPNGを合成。「ステッカー」「フレーム」の2モード |
| **Editor** | [f2sk.github.io/sticker-cam/editor.html](https://f2sk.github.io/sticker-cam/editor.html) | 画像の背景色（緑／青／黒）を除去して透過PNGを作成 |

---

## 権限とプライバシー

このツールが要求する権限は**必要最小限**です。

### 要求する権限

| ツール | 要求する権限 | いつ要求するか |
| --- | --- | --- |
| Camera | **カメラのみ** | カメラを使うときだけ。マイク・位置情報・連絡先などは一切要求しません |
| Editor | **なし** | 権限要求は一切ありません |

- カメラは映像のみを取得します（**音声＝マイクは取得しません**）。
- 位置情報・通知・ストレージ許可などのプロンプトは出しません。

### データの扱い（外部送信は一切なし）

- **サーバーへの通信を一切行いません。** ページを開いた後の全処理は端末内のブラウザだけで実行されます。外部API・解析ツール・広告・CDN読み込みも使っていません。
- **撮影した写真・選んだ画像は端末外に出ません。** 合成もチャンネル除去もすべてブラウザ内の Canvas 上で行い、結果は「ダウンロード」として端末に保存されるだけです。
- 登録したステッカー／フレームPNGは端末内の **IndexedDB** にのみ保存されます（他端末やサーバーとは同期しません）。ブラウザのサイトデータを消せば削除されます。
- ソースは単一HTMLファイルで、コードを読めば通信していないことを確認できます（`fetch`／`XMLHttpRequest`／外部 `<script>` を含みません）。

> 補足: 唯一の外部通信は「GitHub Pages からページ本体（HTML）を読み込む」ときだけで、これは表示のための取得です。読み込み後は完全にオフラインでも動作します（カメラ・画像選択・保存とも可）。

## Camera の使い方

画面上部中央のトグルで **ステッカー** / **フレーム** を切り替えます。

### ステッカーモード（背景の上にPNGを貼る）

1. `PNG選択` … 透過PNGステッカーを読み込み、背景の上に配置
2. 指でドラッグ＝移動、2本指ピンチ＝拡大縮小、端末回転＝ステッカーも追従
3. 背景は初期状態では**カメラ映像**。`写真` を押すと既存写真を背景にできる（左上の `✕` でカメラに戻る）
4. `撮影(JPG)` / `保存(JPG)` … 背景＋ステッカーを合成して保存

### フレームモード（透過フレームの中に写真を収める）

1. `PNG選択` … 透過した窓を持つフレームPNGを読み込み（画面にフィット配置され、これが最終画像の枠になる）
2. `写真` … 枠の中に収める写真を読み込み
3. 写真をドラッグ・ピンチ・回転で窓の中に合わせる
4. `保存(PNG)` … フレームPNGの実寸で書き出し（**透過を保つためPNG保存**。角丸や飾り抜きが黒くなりません）

- 読み込んだPNGは「最近」「お気に入り」タブから再利用できます（★で固定、✕で削除）。

## Editor の使い方

1. `画像を選択する` … PNG/JPG を読み込み
2. 除去色（緑／青／黒）としきい値を選び、背景を透過
3. 回転（±90°・微回転）、`枠を表示`→`切抜実行` でトリミング
4. `透過PNGとして保存`

作成した透過PNGを Camera の `PNG選択` で読み込めば、ステッカー／フレームとして使えます。

## 技術メモ

- **構成**: HTML / CSS / バニラ JavaScript。フレームワーク・外部ライブラリ不使用
- **依存関係ゼロ**: 単一HTMLファイルで完結。CDN・外部フォント・外部スクリプトなし
- **保存先**: ステッカー／フレームは IndexedDB（`sticker-cam`）、出力画像はブラウザのダウンロード
- **カメラ**: `getUserMedia`（映像のみ）。対応端末では露出補正スライダーを表示
- **ホスティング**: GitHub Pages（HTTPS。カメラ利用に必要なセキュアコンテキスト）

### ローカルで動かす

`getUserMedia` はセキュアコンテキスト（HTTPS もしくは `localhost`）でのみ動作します。ローカル確認は簡易サーバー経由が確実です。

```bash
# 例: Python の簡易サーバー
python -m http.server 8000
# → http://localhost:8000/ を開く
```

`index.html` をファイルから直接開くとカメラが起動しない場合があります（画像選択・保存は動作します）。
